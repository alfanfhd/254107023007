# Resources

Folder ini berisi referensi dan sumber belajar yang berguna untuk mata kuliah Pemrograman Mobile.

## Kategori
- **Dokumentasi Resmi**: Flutter, React Native, Android, iOS
- **Tutorial**: Video tutorial, blog post, online courses
- **Tools**: Development tools, libraries, frameworks
- **Best Practices**: Clean code, architecture patterns, security

## Format File
- Gunakan format markdown (.md) untuk link dan deskripsi
- Organisir berdasarkan kategori atau topik

## Template
```markdown
# [Topik]

## Deskripsi
[Deskripsi singkat tentang resource]

## Link
- [Nama Resource](URL)

## Catatan
[Catatan tambahan tentang resource]
```
