# Week 1: Mobile Development Ecosystem & Flutter Refresh

## Tujuan
Membuat aplikasi profil mahasiswa sederhana menggunakan Flutter untuk memahami dasar-dasar pengembangan aplikasi mobile dan ekosistem Flutter.

## Fitur Utama
- Tampilan profil mahasiswa dengan nama
- Informasi mata kuliah "Pemrograman Mobile - Minggu 1"
- Ikon sekolah sebagai visual
- Layout responsif dengan Flutter

## Stack Teknologi
- **Framework**: Flutter
- **Bahasa**: Dart
- **UI**: Material Design
- **IDE**: VS Code / Android Studio

## Cara Menjalankan

### Prasyarat
- Flutter SDK terinstall
- Android Studio / Xcode (untuk mobile development)
- IDE dengan Flutter extension (VS Code / Android Studio)

### Langkah-langkah
1. Pastikan Flutter sudah terinstall:
   ```bash
   flutter doctor
   ```

2. Masuk ke folder project:
   ```bash
   cd 01-week-1-mobile-development-ecosystem-flutter-refresh
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Jalankan aplikasi:
   ```bash
   flutter run
   ```

5. Untuk hot reload saat development:
   - Tekan `r` di terminal
   - Atau gunakan fitur hot reload di IDE
